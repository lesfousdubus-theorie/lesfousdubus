# Sources éditoriales brutes

Ce dossier rassemble les transcriptions et notes de travail ayant servi à rédiger les articles du site.

- `theorie-originale.txt` : transcription de la théorie principale ;
- `voie-de-joyboy.txt`, `live.txt` et `les-dieux.txt` : contenus thématiques complémentaires ;
- `chapitres/` : notes classées par numéro de chapitre.

Ces fichiers ne sont pas publiés tels quels par Astro et ne doivent pas être placés dans `public/`. Le contenu destiné au site est rédigé et structuré dans `src/content/`.
